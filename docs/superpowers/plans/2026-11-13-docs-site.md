# runningtab documentation site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Zensical documentation site for runningtab, written for someone keeping their own company's books, published to GitHub Pages from main.

**Architecture:** `zensical.toml` at the repo root builds `docs/` into `site/`. A separate `.github/workflows/docs.yml` builds on PRs and deploys on main. Pages are drafted by Astra (`codex exec --model gpt-6-astra`) from briefs and checked against the code. A pytest test pins the reference pages' commands and flags to the real CLI.

**Tech Stack:** Zensical ≥0.0.52, uv, just, GitHub Actions (configure-pages, upload-pages-artifact, deploy-pages), typer/click introspection for the docs test.

**Spec:** `docs/superpowers/specs/2026-11-13-docs-site-design.md`

## Global Constraints

- Site URL `https://transpire-dev.github.io/runningtab/`; `repo_url = "https://github.com/transpire-dev/runningtab"`; `edit_uri = "edit/main/docs/"`.
- `zensical>=0.0.52` in a `docs` dependency group only.
- Every workflow action pinned by full SHA with a `# vX.Y.Z` comment; `persist-credentials: false` on checkout; top-level `permissions: contents: read`; `pages: write` + `id-token: write` only on the deploy job, in the `github-pages` environment.
- Builds run `--strict`. Links to repo files outside `docs/` are absolute `https://github.com/transpire-dev/runningtab/blob/main/...` URLs.
- `docs/superpowers/` builds but is not in `nav`.
- Copy: plain direct sentences; no contrastive negation; never "load-bearing", "footgun", "blast radius", "wedge"; no emoji; no marketing words. Nothing the code does not do.
- Transpire facts come only from Gavin. No real Transpire hosts, buckets, secret ids or account ids.
- The Pages "GitHub Actions" source setting and every push/PR need Gavin's go-ahead.
- Commit subjects `subsystem: imperative summary`, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **The site under the `/runningtab/` subpath.** Assets, search and instant navigation must work at the project-pages path. `site_url` gets set, and the deployed URL is checked after the first deploy (Task 9).
2. **Docs drifting from the CLI.** A renamed flag or command must fail a test. `tests/test_docs.py` covers this (Task 2).
3. **README links on PyPI.** PyPI does not resolve relative links, so the shrunk README must use absolute URLs only. A test is added in Task 8.
4. **Broken internal links and anchors.** `--strict` must fail on them. Task 1 deliberately adds a bad link, sees the build fail, then removes it.
5. **A reader running the tutorial with no GCP.** The `--target test` path with `RUNNINGTAB_TEST_*` set must not touch Secret Manager. Task 4 confirms this from the code and by a run Gavin approves.
